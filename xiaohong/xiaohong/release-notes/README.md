# 小鸿AI 固件版本发布记录 (Release Notes)

本目录按版本记录了小鸿AI固件（WS63）的发布说明，每个版本一个 Markdown 文件。

## 版本列表

| 版本 | 发布日期 | 固件包目录 | 说明 |
|------|---------|-----------|------|
| [v2.0.0](v2.0.0_20260823.md) | 2026-08-23 | `20260823_oh7.0_v2.0.0` | OH底座升级到7.0-Release； |
| [v2.0.2](v2.0.2_20260828.md) | 2026-08-28 | `20260828_oh7.0_v2.0.2` | UI的显示缓存小量增大，稍微提升对话文字刷新效果；更多的内存用于增大下行语音数据缓存Slot，以便更大限度提升语音播放流畅性。新增一个不带OpenHarmony框架仅使用海思fbb_ws63 sdk的固件。 |
| [v2.1.0](v2.1.0_20261001.md) | 2026-10-01 | `20261001_oh7.0_v2.1.0` | 新增纯语音对话版本（关闭显示屏和LVGL任务）；打开Mongoose的TLS特性支持https协议，OTA升级包、字库下载切换为Mongoose+https方式；切换到新的OTA服务器地址和智控台地址。 |

## 固件包说明

每个版本目录下包含两个文件：

- `*.fwpkg`：固件升级包（用于烧录/升级）；
- `*_ota.bin`：OTA 升级包（用于在线升级）。
