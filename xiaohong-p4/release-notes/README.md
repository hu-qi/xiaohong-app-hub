# 小鸿SE(P4) 固件版本发布记录 (Release Notes)

本目录按版本记录了小鸿SE(P4)固件（ESP32-P4）的发布说明，每个版本一个 Markdown 文件。

## 版本列表

| 版本 | 发布日期 | 说明 |
|------|---------|------|
| [20260720](20260720.md) | 2026-07-20 | 新增对话交互功能；微调UI交互风格；加快开机速度 |
| [20260716](20260716.md) | 2026-07-16 | 优化触控和UI交互；优化UART RX任务流程 |
| [20260709](20260709.md) | 2026-07-09 | 合并设置页面；移除OTA页面 |

## 固件包说明

每个版本目录下包含以下文件：

- `bootloader.bin`：引导程序；
- `partition-table.bin`：分区表；
- `ohos_liteos_p4_app.bin`：P4 应用固件；
- `flash_args`：烧录参数。
