# 小鸿键盘：浏览器配置自定义键位使用教程

小鸿键盘（xiaohong-kb）支持通过 **浏览器网页** 自定义各物理键的按键映射（单键/组合键/多键宏），配置保存在键盘芯片的 NV 区域，掉电不丢失，**无需重新烧录固件**。

本文档说明如何进入配置模式、使用网页配置页，以及相关的注意事项。

---

## 1. 功能总览

| 项目 | 说明 |
|---|---|
| 进入配置模式 | 先下按 "**O** 键 + 向左键" 组合键，切换进入本地工作模式；再按 "向左键" 或 "向右键" 移动光标高亮选中本地模式页面下的 "按键映射" 按钮，按 ✅️ 键，进入 "按键重映射" 操作指导页面 |
| 配置热点 | 键盘开启 WiFi 热点 **XH-KB_xxxx**（开放热点，无密码） |
| 配置地址 | 浏览器访问 **http://192.168.1.1** |
| 可配置键位 | O 键、❌ 键、✅ 键、上键、下键 五个单键，以及 O+❌、O+✅ 两个组合键 |
| 宏能力 | 每个键位最多 6 步按键序列，每步可含修饰键组合 |
| 生效条件 | 已连接 Dongle 且为正常工作模式（模式0）时，自定义映射发送给 PC |
| 保存位置 | 芯片 NV 区域（NV ID 0x1002），掉电不丢失 |

> 自定义键位映射需要键盘固件支持。当前发布固件（见 `xiaohong-kb/xiaohong/fw/`）已包含该功能。

---

## 2. 进入/退出配置模式

1. 先下按 "**O** 键 + 向左键" 组合键，切换进入本地工作模式；再按 "向左键" 或 "向右键" 移动光标高亮选中本地模式页面下的 "按键映射" 按钮，按 ✅️ 键，进入 "按键重映射" 操作指导页面：
   - 热点名称：`XH-KB_xxxx`
   - 配置地址：`http://192.168.1.1`
   - 操作提示：连接热点后用浏览器打开配置地址即可自定义键位
2. 配置完成后，再次按下 **O 键 + 向左键**，切换进入正常工作模式（热点关闭，返回正常模式页面）。

> 注意： 以下两个组合键已经被系统占用，用于在任何情况下都可以切换：
>
> 1. 切换键盘的工作模式(Always_Up、**O 键 + 向左键**  )：  0-正常工作模式(按键码发往Dongle)，1-本地工作模式(按键码不发往Dongle)
>
> 2. 切换按键的映射模式(Always_Down、**O 键 + 向右键**)：0-使用系统默认的按键编码，1-使用用户自定义的按键编码
>
> 因此，这两个组合键，用户不能修改默认功能，否则将无法正常切换上述两个模式的功能。

---

3. 正常工作时，按下 **O 键 + 向右键**，可以循环切换：使用系统默认的按键编码（顶部状态栏显示 Default）或是 使用用户自定义的按键编码（顶部状态栏显示 Custom）

## 3. 使用网页配置键位

### 3.1 连接热点

手机或电脑打开 WiFi 设置，连接热点 **`XH-KB_xxxx`**（无密码，开放热点）。

### 3.2 打开配置页

在浏览器地址栏输入 **http://192.168.1.1** 并回车，进入键位配置页面。

页面包含 7 个键位卡片，每个卡片可配置：

- **步骤数**：0~6，表示该键按下后发送的按键序列步数（宏），步骤数为 0 时，该键使用系统默认的按键码；
- **每一步**：
  - 修饰键勾选：Ctrl / Shift / Alt / Win 以及右修饰键（RCtrl / RShift / RAlt / RWin），可多选；
  - 按键选择：下拉框选择要发送的按键（A-Z、0-9、Enter、Esc、PageUp/PageDown、F1-F12、方向键等）。

### 3.3 保存与恢复

- **保存配置**：点击页面底部的「保存配置」按钮，键位映射立即写入 NV 并生效；
- **恢复默认**：点击「恢复默认」按钮，所有键位还原为出厂映射。

---

## 4. 配置示例

| 目标效果 | 配置方式 |
|---|---|
| ❌ 键 发送 ESC | ❌ 键 → 步骤数 1，第 1 步：勾选无修饰键，按键选 Esc |
| O 键 发送 Ctrl+C | O 键 → 步骤数 1，第 1 步：勾选 Ctrl，按键选 C |
| ✅ 键 发送 Win+V（粘贴历史） | ✅ 键 → 步骤数 1，第 1 步：勾选 Win，按键选 V |
| 上键 发送 Ctrl+Shift+Esc | 上键 → 步骤数 1，第 1 步：勾选 Ctrl+Shift，按键选 Esc |
| 下键 发送宏「Ctrl+C 后 Enter」 | 下键 → 步骤数 2：第 1 步 Ctrl+C；第 2 步 无修饰键 + Enter |

---

## 5. 生效范围与优先级

- 自定义映射在 **已连接 Dongle 且工作模式为正常模式（模式0）** 时，将按配置发送 HID 报告给 PC；
- **未自定义的键位**（步骤数为 0）保持原有功能不变（见 `README_CN.md` 的「按键定义」章节）；

## 6. 常见问题

**Q1：进入配置模式后，浏览器打不开 192.168.1.1？**

- 确认手机/电脑已连接热点 `XH-KB_xxxx`；
- 确认地址输入为 `http://192.168.1.1`（不是 https）；
- 确认键盘显示屏仍停留在 "按键重映射" 提示页（若已退出，重新按进入配置模式操作步骤进入提示页）。

**Q2：配置保存后按键没有按预期工作？**

- 确认键盘已连接 Dongle，且工作模式为正常模式（模式0，非本地模式）；
- 确认该键位的「步骤数」不为 0（0 表示未自定义，使用默认功能）；
- 部分按键（如系统组合键）被自定义后会覆盖系统功能，请检查是否误配置。

**Q3：重新烧录固件后，自定义配置会丢失吗？**

- 自定义键位配置保存在芯片 NV 区域。烧录时若勾选烧录 `ws63_all_nv.bin`，NV 区域会被刷新导致自定义配置丢失；**建议不勾选烧录 NV 区域**，可保留自定义信息。
