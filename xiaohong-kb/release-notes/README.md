# 小鸿VibeCoding键盘 固件版本发布记录 (Release Notes)

本目录按版本记录了小鸿VibeCoding键盘固件（键盘端WS63 + 接收端Dongle BS21E）的发布说明，每个版本一个 Markdown 文件。

## 版本列表

| 版本 | 发布日期 | 说明 |
|------|---------|------|
| [v3.0.0_20260907](v3.0.0_20260907.md) | 2026-09-07 | 新增键盘作为BLE外设功能（默认关闭，供试用）；调整按键分发路径 |
| [v2.0.0_20260823](v2.0.0_20260823.md) | 2026-08-23 | OH底座升级到7.0-Release；版本改为2.0.0 |

## 固件包说明

每个版本包含两个固件：

- `xiaohong_kb_ws63.fwpkg`：键盘端 WS63 的固件；
- `xiaohong_kb_bs21e_dongle.fwpkg`：接收端 Dongle BS21E 的固件。
