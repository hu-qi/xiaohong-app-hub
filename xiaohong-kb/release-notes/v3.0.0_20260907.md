# 小鸿VibeCoding键盘 v3.0.0_20260907 发布说明

- 发布日期：2026-09-07
- 固件包目录：`xh-kb-v3.0.0_20260907`
- 固件包文件：
  - `xiaohong_kb_ws63_20260907_support_sle_only.fwpkg`：键盘端WS63固件（默认版本，仅支持SLE星闪协议，需配合Dongle使用）；
  - `xiaohong_kb_ws63_20260907_support_sle+ble.fwpkg`：键盘端WS63固件（试用版本，同时支持SLE/BLE两种协议）；
  - `xiaohong_kb_bs21e_dongle.fwpkg`：接收端Dongle BS21E固件（本版本无更新）。

## 更新内容

小鸿KB(WS63)：调整按键分发路径，新增键盘作为BLE外设功能，可直接被PC(蓝牙Central)扫描、连接和使用。

本版本开始，键盘端除原有 SLE-HID（通过SLE-Dongle与PC桥接）外，新增 BLE-HID 能力，键盘可直接作为 BLE 外设被 PC 扫描、连接和使用。

## 注意事项

- 键盘作为 BLE 外设的功能**尚未完全稳定，默认关闭**，需开发者自行打开 `xiaohong/config.gni` 中的 `config_ble_enable` 配置后重新编译固件；
- 该功能仅供感兴趣的开发者试用、完善、改进，欢迎提交PR；
- 接收端Dongle无更新，`xiaohong_kb_bs21e_dongle.fwpkg` 与上一版本一致。
